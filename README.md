# 🎯 Number Guessing Game (Python CLI)

A fun terminal-based number guessing game built with Python.  
The computer generates a random number, and the player must guess it within a limited number of tries.

---

## 🚀 Features

- Multiple difficulty levels
- High score saving using JSON
- Input validation
- Replay option
- Works on Windows, Linux, and Android (Pydroid 3)

---

## 🎮 Difficulty Levels

| Level   | Range        | Attempts | Score Gain |
|--------|-------------|---------|-----------|
| Easy   | 1 – 20      | 5 tries | +1        |
| Medium | 1 – 40      | 5 tries | +2        |
| Hard   | 1 – 60      | 5 tries | +3        |
| Master | 1 – 80      | 5 tries | +4        |
| Legend | 1 – 100     | 5 tries | +5        |

---
